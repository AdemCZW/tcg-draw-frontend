# VaultDraw 遊戲規則

這份寫的是**規則本身**，不是程式怎麼做的。用白話寫，給人看的。

最後更新：2026-08-25

---

## 一、點數

- 儲值換點數，**1 點就是 1 點**，站內用。
- **點數不能換回現金。** 這不是產品選擇，是法律紅線（刑法 266 條的對價關係）。
- 點數可以用來：抽卡、在市場上買別人的卡。
- 不想要的卡可以**賣回給開池的人**換點數（見第四節），但換到的還是點數，不是錢。

---

## 二、開池（賣家做的事）

### 一個池由這些東西組成

| 項目 | 說明 |
|---|---|
| 標題 | 池的名字 |
| 票價 | 抽一次多少點 |
| 獎品 | 每張卡的賞別、數量。卡是**挑**出來的（自己的卡冊或卡片目錄），不是打字打出來的 —— 所以每一張都有卡號、系列、卡圖與版本 |
| **買回價** | 每個賞別一個金額，賣家承諾用這個價買回 |
| 到期日 | 時間到就關池 |

### 賞別

`A 賞`（最高）、`B 賞`、`C 賞`、`D 賞`。數字越前面越好。

**「最後賞」目前就是池裡的一張普通獎品**，抽走最後一籤**沒有**額外贈獎。（其他平台有這個玩法，我們現在沒有，所以不會這樣寫在頁面上。）

### 買回價怎麼設

**按賞別設，整池只要填四個數字。**

```
A 賞  買回 3,000
B 賞  買回   800
C 賞  買回   300
D 賞  買回   120
```

同一個賞別裡的卡價值本來就相近，所以不用一張一張填。某張卡特別貴的話可以單獨改那一格。

**這個數字是承諾，不是估價。** 玩家要賣回來，賣家就得用這個價買。錢從賣家自己的帳戶出。

### 一條硬規則：買回總額不能超過票收

```
所有獎品的買回價加總  <  票價 × 總籤數
```

不然「把整池抽光再全部賣回」就會賺錢，那是印鈔票。系統會在開池時擋下來。

### 開賣後不能改

開池的當下，整份獎品清單（**含買回價**）會被封存成一組雜湊公開出去。之後任何改動都會被驗算抓到。

所以賣家**不能**在有人抽到好卡之後偷偷調降買回價。

### 新賣家的限制

第一個池有籤數與總額上限。這是替代保證金的做法——把第一次違約的最大損失壓住。

## 三、抽卡（玩家做的事）

1. 選一個池，選要抽幾支（1／3／5／10）
2. **自己挑籤位**——不是系統隨機給你，是你自己點格子
3. 付點數，開卡
4. 卡直接進你的卡冊

### 抽到的卡，你有三條路

| 選擇 | 結果 |
|---|---|
| **留著** | 卡放在卡冊裡（有寄存期限） |
| **申請出貨** | 賣家寄實體卡給你 |
| **賣回** | 用賣家承諾的買回價換回點數 |
| **上架市場** | 賣給其他玩家 |

---

## 四、賣回

- 買回價**在你抽卡之前就看得到**，寫在池的獎品清單上。
- 你決定要賣回，就用那個價成交。
- 錢從**賣家**的帳戶出，不是平台出。
- 卡回到賣家手上（本來就還沒寄出）。

**為什麼不是平台回收：** 平台買回自己送出的獎品在台灣是明文禁止的（電子遊戲場業管理條例第 14 條）。而且平台掏錢買回會變成印鈔票——賣家可以把價格喊高再自己回收。

---

## 五、出貨

- 你申請出貨後，賣家要在期限內寄出。
- 收到卡之後確認收貨；不確認的話，**7 天鑑賞期**滿也算完成。
- **賣家沒寄出**：期限到了，點數退還給你，賣家記一次違約。

### 違約累積會怎樣

違約次數超過門檻，那個賣家**不能再開新的池**。

---

## 六、賣家什麼時候拿到錢

**不是抽卡當下。**

```
玩家抽卡
   ↓
點數記在賣家名下，但是「保留額」——看得到、動不了
   ↓
賣家寄出 + 玩家確認收貨（或 7 天鑑賞期滿）
   ↓
那一筆才變成可動用
```

**逐筆釋放**，不用等整池抽完。第 3 天寄出的那張，第 10 天就結清，不必等池子在三週後才賣光。

沒寄出的那些，期限到了直接退還買家。

---

## 七、池什麼時候結束

**三種情況：**

1. **抽完了** —— 所有籤位都被抽走
2. **到期了** —— 賣家設的日期到了
3. **賣家提前關池**

**到期或關池只是停止販售。** 已經抽出去的卡，出貨與鑑賞期照跑完；沒被抽走的籤位，那些卡回到賣家手上。

大獎有沒有被抽到**不影響**——沒抽到就是回賣家。

---

## 八、公平性

### 籤序在開賣前就決定好了

- 開池時，系統產生一組隨機種子，把**種子的雜湊**公開出去（種子本身不公開）。
- 籤序由那組種子決定。雜湊一公開，籤序就改不了——改了對不上。
- 那份雜湊還包含**整份獎品清單**（卡片、**卡片版本**、數量、買回價），所以開賣後偷換卡或改買回價也會被抓到。
- **版本也算**：同一組卡號的普卡與大師球鏡面是兩張不同的卡（實測價差近兩萬倍），換掉版本一樣對不上。
- 池結束後**種子會公開**，任何人都能自己重算一次驗證。

### 隨機來源

客戶端種子用 **drand**（一個公開的分散式隨機信標）的**未來輪次**——開池的當下那個數字還不存在，所以賣家沒辦法反覆試到對自己有利的種子。

### 你可以自己驗

每個池都有驗算頁，把種子和獎品清單餵進去重算，看籤序對不對得上。**不需要相信我們，你自己算。**

---

## 九、賣家自己抽自己的池

**不禁止。** 錢從他自己流到自己，不會憑空生出點數。

但**自抽不計入公開的剩餘籤數**——不然賣家可以自己抽幾支讓池看起來很熱門（「剩 3/50」），騙真人跟進。

目前 **0%**。

## 還沒定案的事

這些寫在這裡是為了誠實，不是因為忘記：

- **賣家標示的「參考市值」** 目前沒有外部依據，是賣家自己填的。所以它**不參與任何金額計算**，只是顯示用，頁面上會明說。真正有約束力的數字是買回價。
- **平台不代管實體卡**，卡由賣家直接寄給買家。系統不知道賣家手上實際有沒有那張卡。
- **保底／天井**（抽幾次必定出大獎）沒有做。
- **開池保證金**沒有做，用「新賣家額度上限 + 違約累積」替代。
