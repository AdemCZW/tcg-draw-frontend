# 用收藏積分兌換實體卡包：法律與防刷

## 0. 先講結論

**可以做，但只有一種形狀是低風險的：**
「固定數量的已確認積分，換一包**指定型號、原封**的擴充包；平台不代開、不收回、不能換回任何東西。」

| 問題 | 一句話答案 |
|---|---|
| 會不會變賭博 | 單看「免費積分換一包原封卡包」，參加者沒有押上任何財物，對價很難成立。**風險來自積分跟錢的關聯**：能自買自賣刷成交分、未來收手續費、或有任何折現／收回通道，這三個任一出現，對價論證就開始成立 |
| 公平法贈品上限 | 買卡分：以累積消費算，一包卡包遠低於上限。登記分：不以交易為要件，原則上不列入。**卡包內容隨機不等於「贈獎」**，只要給的是確定的那一包〔推論〕 |
| 消保／個資 | 要公告活動辦法、寫清楚變更終止規則；寄送要蒐集姓名地址電話，要告知用途與保存期限 |
| 電支／儲值 | 免費取得、不能折抵別人的商品 → 不是儲值。**一旦能拿來折抵購物款就踩線** |
| 發票／稅 | 個人未登記階段不涉發票；登記後「抽獎獎品、銷貨附送贈品」可免開發票。單包價值遠低於所得申報門檻 |
| 寶可夢商標 | 發真品卡包沒問題（權利耗盡）。宣傳不能看起來像官方活動，**不要用官網圖片** |
| 防刷 | 鑑定編號無法自動驗證，**登記分幾乎零成本可偽造**。兌換只能看「經過人工確認＋冷卻期」的積分 |

**跟既有設計的衝突要先處理**：收藏家等級規格（`2026-09-15-collector-level-design.md`）與
`src/shared/collector.ts` 的註解都寫著收藏積分「不能兌換任何東西」。要做兌換，規格要先改，
而且建議**等級分與可兌換額度分成兩個數字**（第 3 節）。

## 1. 法律面

### 1.1 刑法賭博罪：對價在哪裡

**條文與要件。** 刑法第 266 條處罰賭博財物的人（五萬元以下罰金），
2022 年增訂第 2 項把網路賭博明文納入；營運方要面對的是第 268 條（意圖營利供給賭博場所或聚眾賭博）。
臺灣高等檢察署的法治文章把賭博罪拆成三件事：結果由偶然決定（射倖性）、
場所（含網路）、以及賭的是財物，形容射倖性是「無法在事前就可以預知結果」。

實務上真正的判斷點是**參加者有沒有押上會輸掉的財物**。這也是既有文件一再寫的「對價關係」。
（`research-oripa-landscape.md` 已整理：付費抽卡的爭點是「玩家買的是機會本身」。）

**逐一套到收藏積分：**

| 積分來源 | 參加者付出了什麼 | 對價風險 |
|---|---|---|
| 登記一張鑑定卡 | 什麼都沒付，卡也還在自己手上 | **低**。沒有財物得喪，形同免費參加 |
| 站內買到一張卡 | 付了卡價，但換到的是那張卡本身（等價交換），積分是附帶 | **低到中**。只要積分**不能用錢直接或間接換到**，卡包兌換沒有額外押注 |
| 將來若收平台手續費，每筆成交都付費 | 付的是服務費，積分跟著費用走 | **中**。等於「付手續費 → 拿積分 → 換隨機卡包」，有人會主張這是用錢買積分〔推論〕 |

**卡包「內容隨機」本身不是問題的核心。** 原封擴充包是在超商、玩具店公開販售的普通商品，
官方建議售價 NT$54（2026-05 起新品），不因內容隨機而被當成賭具。
一番賞類的實務討論也把「每抽必得一個商品」視為區分賭博與商品買賣的重點；
業者作弊時追究的是詐欺與消保法，不是賭博（見來源）。

**什麼會讓它滑向賭博**〔推論〕：

1. **積分可以用錢取得**：直接賣積分、或站內交易可以自買自賣刷分（等於花運費與時間買積分）。
2. **有折現或回收通道**：平台收回卡包或開出的卡、卡包換回點數、積分換點數。
   這就把「押注 → 隨機結果 → 換回財物」三段補齊了。
   `HANDOFF.md` 的兩條紅線（點數不可換現金；平台不可買回自己送出的獎品，電子遊戲場業管理條例 §14-II-2）
   在這裡**同樣適用**，理由相同。
3. **獎品本身變成射倖**：「兌換一次隨機給一包或一盒」「隨機抽中高價卡盒」，或平台代開後把卡給你。
   這時隨機性由平台製造，而不是商品本來就有。
4. **兌換需要補差價**：「30 分＋49 點換一包」——只要加入任何付費，就是用錢買一次隨機結果。

**台灣的社會背景。** 2026-05 媒體報導某線上一番賞 App 遭 20 人自救會控告、
累計損失約 5,000 萬元（報導未具名平台）。律師意見談的是加重詐欺，並提到因商品可變現而有洗錢疑慮。
這說明**「可變現」就是主管機關與媒體注意的那個點**，兌換設計要讓卡包出站後與平台的金錢完全斷開。

**「集點送」「會員點數兌換」的一般定位。** 超商集點、信用卡紅利換商品，都是「消費附帶的無償利益」，
一般不被當作賭博，而是落在公平交易法的贈品規範。我**沒有找到**主管機關針對「集點換隨機商品」
是否構成賭博的函釋，這一點列為查不到（第 6 節）。

### 1.2 公平交易法與「事業提供贈品贈獎額度辦法」

**依據。** 公平交易法第 23 條：事業不得以不當提供贈品、贈獎的方法爭取交易機會，額度由主管機關定。
違反時依第 42 條，得限期改正並處 5 萬到 2,500 萬元罰鍰，屆期不改可按次處罰。
「事業」包含個人經營者，不是公司才適用。

**辦法重點（2015-03-19 發布）：**

| 條 | 內容 | 對卡包兌換的意義 |
|---|---|---|
| §2 贈品 | 為爭取交易，**附隨、無償**提供有市場價值的商品 | 買卡分換卡包 → 較像贈品 |
| §2 贈獎 | 於商品之外，**依抽籤或其他射倖方式**無償提供 | 誰拿到、拿到什麼由機率決定才是贈獎 |
| §3 第 1 款 | 不以交易為前提的促銷（如免費試用）不列入 | 純登記分換卡包 → 原則上不適用本辦法 |
| §4 | 贈品上限：商品價值 ≥100 元者為其 1/2；<100 元者為 50 元 | 見下方試算 |
| §5 | 全年贈獎總額上限：前一年銷售額 7.5 億以下者 1.5 億 | 規模上碰不到 |
| §6 | 最大單項獎額 500 萬元 | 碰不到 |
| §7 | 贈品價值依宣稱價值、取得成本、零售價依序認定 | 卡包以官方建議售價或進貨成本計 |

（有一篇實務文章寫最大獎是「基本工資 120 倍」，與法規資料庫現行條文的 500 萬元不符，以法規資料庫為準。）

**卡包內容隨機，是贈品還是贈獎？**〔推論〕
辦法定義的射倖性是「提供的方式」依抽籤決定。兌換者拿到的是**確定的一包**指定商品，
包內卡片隨機是商品本身的性質（就像送一個盲盒），所以較接近**贈品**。
會被當成贈獎的是：兌換時隨機決定給一包還是一盒、隨機決定誰能換到、或平台代開後把結果當獎品給。
**我沒有找到公平會針對「贈送盲盒類商品」的函釋**，這個定性要請律師確認。

**集點怎麼算上限。** 實務文章的說法是用「達成集點條件所需的總消費金額」當商品價值來比
（這是業界整理，**我沒有找到公平會原文**）。試算：

- 假設 30 分換一包 NT$54，若全部是買卡分，代表 30 筆站內成交；只要成交總額 ≥ NT$108 就在 1/2 上限內。鑑定卡單價遠高於此，**不會超標**。
- 麻煩在**混合來源**：如果被認定「登記」也算爭取交易（平台是免費服務），服務價值等於 0、落在「<100 元」那一格，上限 50 元，**NT$54 的卡包會略超**〔推論〕。
  降低爭議的做法：卡包取得成本控制在 NT$50 以內（或以進貨成本計價），或兌換門檻中要求至少若干筆站內成交。

**活動資訊不實也算違法。** 第 21 條（不實廣告）與第 25 條（欺罔或顯失公平）是更常被用到的條文：
廣告寫「集滿就送」卻缺貨、臨時改門檻、無故取消資格，都在射程內。

### 1.3 消保法與個資法

**消保法。**

- 第 22 條：業者要確保廣告內容真實，對消費者的義務不低於廣告。
  活動頁寫的門檻、商品型號、數量、寄送時間都是承諾。
- 第 11、12 條：定型化條款要平等互惠，違反誠信、顯失公平的條款無效。
  「本平台保留隨時修改或終止活動之權利」這種一句話帶過的條款，在爭議時很可能站不住〔推論〕。

**活動辦法建議至少公告這些：**

1. 活動期間、誰可以參加（是否限台灣地址、未成年是否需法定代理人同意）。
2. 積分怎麼來、什麼時候變成「可兌換」、什麼情況會扣回。
3. 兌換門檻、指定商品型號、每人上限、每期數量；缺貨時怎麼處理（例如順延或換成等值的**另一個指定型號**，不是換成錢）。
4. **積分沒有現金價值、不能轉讓、不能折抵任何交易、不能換回點數或現金。**
5. 變更與終止：提前公告（例如 30 天）；公告前已達門檻的人在期限內仍可兌換；已寄出的不追回。
6. 違規處理：偽造登記、分身、互刷，會取消未兌換積分與停權，已兌換者可要求返還或列入黑名單。
7. 個資用途與保存期限（見下）。

**個資法。** 兌換實體商品一定要蒐集收件人姓名、地址、電話。要做到：

- 蒐集時告知目的（寄送贈品、防止重複兌換）、利用期間、方式與當事人權利（第 8 條）。
- 只用在告知的目的內，**不拿寄送資料去做行銷**；不在告知範圍外交給第三方（物流除外並要寫明）。
- **不要收身分證字號**：單包價值遠低於稅務申報門檻（1.4），沒有必要。
- 公告兌換名單時遮蔽（實務文章建議的做法），或乾脆不公告。
- 地址與電話若用來做「同一地址只能兌換一次」的去重，要寫進告知事項，並訂保存期限。

### 1.4 電支條例、發票與稅（簡述）

**電子支付／儲值。** 電子支付機構管理條例第 4 條把「紅利積點整合及折抵代理收付實質交易款項」
列為需許可的業務。媒體引述金管會規劃時的說法：用錢買點數再消費，就跟儲值一樣。
收藏積分若**免費取得、只換平台自己準備的卡包、不能折抵任何人的商品**，就不是儲值，也不是代收付〔推論〕。
**踩線的做法**：積分折抵站內買卡價款、積分換錢包點數、積分可轉給別人。
`payment-models.md` 第 0 節已說明：只要做儲值，代理收付的金額豁免當場失效。

**發票。** 營業稅法第 3 條第 3 項把無償移轉貨物「視為銷售」；但財政部函釋另外排除
抽獎送出的獎品、銷貨附送的贈品等供本業使用的情形，可免開發票，進項稅額仍可扣抵，
前提是贈品成本如實入帳（台北國稅局 2026-04-28 提醒）。
現在是個人、無商業登記，不涉發票；**登記之後**卡包進貨要取得發票、以贈品或行銷費用入帳。

**所得稅。** 若被定性為機會中獎（贈獎），實物以購入發票金額計價；
扣繳 10% 的門檻是單次超過 2 萬元，同一人全年給付不超過 1,000 元可免填報。
一包 NT$54 的卡包遠低於兩個門檻，**不需要跟兌換者要身分資料**。
若被定性為贈品，更不涉中獎所得。

### 1.5 寶可夢商標、著作權與官方規範

**發真品卡包本身沒有問題。** 商標法第 36 條第 2 項（權利耗盡）：
合法流通的真品再轉手，不受商標權拘束。從正規通路買原封擴充包再送出，屬於這種情形。

**宣傳要避開的是「看起來像官方活動」。** 智慧財產局整理的合理使用案例：
指示他人商品可以使用商標，但不能讓人誤以為有授權、代理或合作關係；
有判決認為把他人商標當網店大頭貼、說明字體又不顯眼，構成侵權。套到這裡：

- 活動名稱用自己的（例如「收藏積分兌換」），**不要叫「寶可夢收藏活動」**。
- 商品名稱照實寫成說明文字：「寶可夢集換式卡牌遊戲 擴充包『〇〇』一包」。
- 不把官方標誌、皮卡丘等角色圖當主視覺或按鈕圖示。
- 加註「本活動由 VaultDraw 舉辦，與 The Pokémon Company、Nintendo 等權利人無關，卡包為市售商品」。
  （這跟 `collector.ts` 刻意不用官方用語「訓練家」「冠軍」的理由一致。）

**圖片：不要用官網的。** 台灣官方「訓練家網站」的利用規約寫明站內照片、影像等著作權屬於官方，
禁止複製、散布與營利目的的使用。建議**自己拍實體卡包的照片**，尺寸適中、不當成大型橫幅。
包裝上的插畫本身仍有著作權，拍自己要送出的真品做商品說明是市場常態，但我**沒有找到**明確判決或函釋，列為低到中風險〔推論〕。

**不要用官方非賣品當獎品**〔推論〕：比賽用 Prize Pack、標示非賣的促銷卡，
官方規約另有禁止轉讓贈品／獎品的條款（針對其自家活動）。用市售擴充包最單純。

## 2. 防刷面

### 2.1 前提：登記分幾乎可以免費偽造

`cert-verification-alternatives.md` 的結論：PSA 編號沒有公開的校驗碼，不打外部 API 就無法判斷真假。
全站唯一索引只擋「同一個編號登記兩次」，擋不住「亂填一個沒人用過的號碼」。
**所以一旦積分能換實體卡包，每 1 分就有 NT$1.8 的現值，登記表單就變成印鈔機。**
等級徽章被刷只是面子問題；卡包被刷是實際的貨品與運費損失。

### 2.2 刷法清單

| # | 刷法 | 怎麼做 | 成本 |
|---|---|---|---|
| A1 | 假編號 | 填格式合法但不存在的號碼 | 0 |
| A2 | 抄真編號 | 從 PSA Pop、eBay、社群貼文抄別人的號碼 | 0；還會讓真正的持卡人登記不了 |
| A3 | 登記後兌換、兌換後刪除 | 刷到門檻 → 兌換 → 刪掉登記，扣回變負分但卡包已寄出 | 0 |
| A4 | 腳本大量登記 | 自動化送出表單 | 低 |
| B1 | 分身帳號 | 每個帳號各刷到門檻，換多包 | 手機號或 Email 成本 |
| B2 | 代收地址 | 多個帳號寄到同一處或超商取貨 | 低 |
| B3 | 買賣帳號 | 積分不能轉讓，但整個帳號可以賣 | 低 |
| C1 | 互刷成交 | 兩個帳號，一張卡來回買賣，每次結案 +1 | 運費；第一階段站外付款，甚至不用真的寄 |
| C2 | 超低價假成交 | 標價 1 元自買自賣 | 0 |
| C3 | 結案後站外退款 | 平台看不到站外的錢，成交分照拿 | 0 |
| C4 | 找朋友集團互買 | 小圈子輪流當買家 | 低 |
| D1 | 檢舉濫用 | 惡意檢舉別人的登記，讓對方被扣分 | 0 |
| D2 | 內部人員 | 後台直接加分或放行審核 | — |

### 2.3 防線與取捨

**最關鍵的兩條：**

1. **「可兌換」只看經過確認的積分，確認需要人工看過照片與 PSA 頁面。**
   把收藏積分拆成兩個數字：**等級分**（照現行規格，登記即 +1，只影響徽章）與
   **可兌換額度**（只有「已確認」的事件才入帳）。登記要確認，需上傳 slab 標籤特寫＋
   寫有 VaultDraw、使用者名稱、日期的手寫紙條合照，由人工點開 `psacard.com/cert/{n}`
   對照卡名與 PSA 官方掃描（`cert-verification-alternatives.md` E-4、E-5、E-6）。
   → 直接擋掉 A1、A2、A4；成本是人力，但兌換量有上限，審核量也有上限。
2. **冷卻期＋兌換時才扣額度，扣回可以變負數並凍結。**
   事件確認後再等 30 天（涵蓋檢舉與訂單爭議期）才變成可兌換；兌換從額度扣掉。
   之後才發現是假的 → 額度記負數、凍結兌換與徽章、依辦法處理帳號，**不向對方要錢**
   （追討一包卡包的成本比卡包高，而且把事情變成金錢債務）。
   → 擋掉 A3，壓低 C3、D1 的收益。

**其他防線：**

| 防線 | 擋什麼 | 取捨 |
|---|---|---|
| 每帳號上限（例如每季 1 包、終身 N 包）＋每期總量公告 | 所有刷法的上限 | 真正的大收藏家覺得不夠；但這是控制損失最直接的一條。數量要寫進辦法（公平法第 21 條） |
| 同一個鑑定編號一生只給一次買卡分（不論轉手幾次） | C1 來回互刷 | 真實的多次轉手也拿不到分，可接受 |
| 同一對買賣帳號只算第一次成交；賣家須有與其他人的成交紀錄 | C1、C4 | 熟客重複交易不加分 |
| 最低成交金額（例如 NT$500） | C2 | 低價卡交易不加分 |
| 買卡分也要冷卻、且訂單結案後無爭議 | C3 | 第一階段站外付款，平台**無法**真正驗證付款，只能靠冷卻＋檢舉。**建議第一階段兌換額度不算買卡分** |
| 手機 OTP 一號一帳號，或 LINE 綁定 | B1 | 多蒐集一項個資，要寫告知；LINE 帳號也能多開，只是提高成本 |
| 收件地址／電話去重（每期每地址 1 包） | B1、B2 | 同住家人會被擋；超商取貨門市不能當去重依據 |
| 實名（身分證） | B1、B3 | **不建議**。個資負擔重、門檻高，而單包價值不值得 |
| 編號格式與區間檢查、連號與密集登記標記 | A1、A4 | 零成本，但只能排除明顯假號（E-1、E-3） |
| 檢舉成立才扣分，檢舉人頻繁不成立則降權 | D1 | 需要一個後台動作定義「檢舉成立」（規格已列為待決） |
| 所有加扣分走流水帳、後台操作留操作人 | D2 | 規格已採流水帳，補上操作人欄位 |
| 不做排行榜（規格已決定） | 刷分動機 | 無 |

## 3. 風險最低的可行做法

1. **獎品固定、原封、市售**：每一期指定**一個型號**的繁中擴充包，寫明型號與官方建議售價。
   不做「隨機一包或一盒」「神秘福袋」「隨機高價卡」。取得成本若能壓在 NT$50 以內，連 1.2 的混合來源爭議也避開。
2. **用詞是「兌換」不是「抽」**：不寫中獎、爆卡、機率；不展示「有人換到後開出什麼」。
3. **平台不代開、不直播開包、不收回卡包或開出的卡、不接受卡包換點數。**
   兌換者開出的卡若拿到站內市場賣，是使用者之間的交易，平台照一般規則處理，不給任何「兌換來源」的特別待遇。
4. **兩個數字**：等級分（徽章用）與可兌換額度（兌換用）分開；兌換只扣額度、不降等級。
5. **第一階段只算「已人工確認的登記分」**，冷卻 30 天；買卡分等到站內金流上線、付款可驗證後再納入。
6. **上限**：每帳號每季 1 包、每期總量公告、同一收件地址／電話每期 1 包、手機 OTP 綁定。
7. **扣回**：可變負數、凍結兌換、不追討金錢。
8. **活動辦法頁**照 1.3 的七項寫；變更提前 30 天公告，公告前已達門檻者可在期限內兌換。
9. **個資只收寄送所需**：姓名、地址、電話；不收身分證字號；告知保存期限，活動結束後刪除。
10. **收藏積分與錢包點數在資料表、API、畫面上完全分開**（規格已如此），任何端點都不能讓兩者互轉。
11. **先改規格再做**：把 `2026-09-15-collector-level-design.md` 的「不能兌換任何東西」改成上面的有限兌換規則，並同步 `src/shared/collector.ts` 的註解。
12. **上線前給律師看活動辦法**，特別是 1.2 的「隨機內容商品算贈品還是贈獎」與「登記是否算爭取交易」兩點。

## 4. 一定不要做

- ❌ **積分可以轉讓**（含轉給分身、贈送好友）。
- ❌ **積分可以折現**，或換成錢包點數、折抵站內任何交易的價款（電支條例 §4＋刑法對價）。
- ❌ **可以用錢買積分**，包含「付手續費送積分」「儲值送積分」「兌換時補差價」。
- ❌ **平台收回卡包或開出來的卡**，或卡包可以換回點數（電子遊戲場業管理條例 §14-II-2 同一個道理）。
- ❌ **平台代開卡包、直播開包、把開出的結果當獎品**（隨機性變成平台製造，滑向贈獎與賭博）。
- ❌ **兌換內容本身隨機**：一次可能拿到一包也可能拿到一盒、隨機抽高價卡。
- ❌ **允許兌換者之間交易「兌換資格」或帳號**（辦法中明文禁止並停權）。
- ❌ **未經確認的登記分就能兌換**。
- ❌ **使用官網圖片、官方標誌當主視覺，或讓活動名稱看起來像官方合作。**
- ❌ **用官方非賣品、比賽獎品包當兌換品。**
- ❌ **「保留隨時修改或終止」一句帶過**，不給已達門檻者兌換期限。
- ❌ **向兌換者收身分證字號**或把寄送資料拿去行銷。
