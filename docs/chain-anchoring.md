# 公平性承諾的外部時間戳：要不要上鏈

> 產出日期：**2026-09-06**。這一輪的產出是**一個獨立原型 ＋ 這份判斷**。
> **沒有動 `src/`、`server/`、`vite.config.ts`、路由，或任何進建置的東西。**
> 沒有申請金鑰、沒有連任何鏈、沒有錢包、沒有送出任何交易（主網與測試網都沒有）。
>
> 起點是使用者看完 [vinciworld-comparison.md](vinciworld-comparison.md) 之後的一句話：
> 「如果我想要一部分區塊鏈發展，我覺得是可以考慮借鏡。」
> **這份文件不推翻那一份的 D-1（不代幣化），它站在那一條上面。**

## 結論先講

**不上鏈。用 RFC 3161 打三家獨立的公開 TSA，外加 OpenTimestamps 當長期底墊。兩個都是 $0。**

走到這裡的路徑只有兩步，而且順序不能顛倒 —— **先看死線，再看錢**：

1. **錨定必須早於 drand 那一輪出現，預算約兩分鐘**（見 §1.3）。
   這一條就刷掉了 OpenTimestamps（實測 6〜12 小時才寫一次 Bitcoin）與 GitHub（時間本身可偽造）。
2. 過得了死線的剩下：各條 L2、Solana、Sigstore Rekor、RFC 3161 TSA。
   **其中只有 TSA 同時做到「秒回、$0、而且不用持有加密貨幣」。**

**上鏈輸掉的地方不是錢** —— Base 每池錨一筆、一天 100 個池，實測是**一年 12 美元**。
**輸的是持幣**：台灣《虛擬資產服務法》2026-06-30 三讀通過、從登記制改成許可制，
而「非金融公司只持幣付 gas 算不算經營虛擬資產業務」**法條沒有明文豁免、子法未定、查不到官方函釋**。
為了一個免費方案就能做到的事去踩那個不確定性，不划算。

**但這份文件真正要你先做的不是這兩個，是第 0 步：把 leaf 的規格定死並公開**（§3.2）。
成本零、不碰任何紅線，而且**沒有它，錨到哪裡都一樣沒用**。

## 零、界線

讓 Renaiss 對台灣主體違法的**不是區塊鏈本身**，是兩件具體的事：
**USDT 計價**（所以存在「站內資產 → 交易所 → 新台幣」這條路）與**平台自己買回**。鏈只是載體。

| | |
|---|---|
| ✅ 做 | 錨定 `commit_hash` / `manifest_hash` / drand 輪次 / 總籤數 —— 就是 32 bytes 的雜湊 |
| ❌ 不做 | 代幣化卡片、任何加密貨幣計價、平台買回、錢包連上之後可以買賣任何東西 |

**做原型的過程中沒有出現任何「使用者可以擁有／交易某個鏈上資產」的東西。**
原型頁面把這條界線印成第三條圖例，跟「真的／模擬」並列。

## 一、先把現況讀懂

### 1.1 已經有的（讀碼）

| 環節 | 位置 | 做了什麼 |
|---|---|---|
| server seed | `server/src/pools-service.ts:159` | `randomBytes(32)`，下一行 `assertSeedEntropy()` 擋低熵 |
| manifest | `src/shared/fairness.ts:129-148` | v4：`prizeId\|tier\|total\|name\|setCode\|cardNo\|grader\|grade\|certNo\|refPrice\|buyback\|variantId` |
| commit | `src/shared/fairness.ts:163-170` | `SHA256(server_seed_bytes ‖ manifest_hash_bytes)` |
| client seed | `server/src/pools-service.ts:79,88-93` | **drand 未來輪次**，`FUTURE_ROUNDS = 4`（約 2 分鐘後） |
| 籤序 | `src/shared/fairness.ts:223-239` | HMAC-SHA256 位元流跑 Fisher-Yates，拒絕取樣避免取餘偏差 |
| reveal | `server/src/pools-service.ts:833-838` | 售罄／關池後 `server_seed` 才公開 |
| 自己驗 | `src/shared/fairness.ts:284-320` `verifyReveal()` | 四條檢查，瀏覽器裡重算 |

**缺的只有一件事**：`commit_hash` 存在**我們自己的 Postgres 裡**。
「這份承諾在開賣前就長這樣」目前唯一的證人是我們自己。
（使用者的 memory 裡本來就有這條待辦：承諾雜湊要有外部時間戳，原本規劃寫進公開 GitHub repo。
**§3.1 會說明為什麼那個規劃行不通。**）

### 1.2 錨的是 `commit_hash`，包成一層 leaf

`manifest_hash` 只綁獎品清單、不綁種子，錨它擋不到「種子被換」。
`commit_hash` 兩件事都涵蓋。但光錨那 32 bytes，外面看不出它是哪個池的承諾，所以：

```
leaf = SHA256(
  "vaultdraw/anchor/v1" | poolId | commit_hash | manifest_hash
  | commit_version | client_seed_source | total_tickets
)
```

- 前綴 `vaultdraw/anchor/v1` 是網域分隔，讓這個雜湊不可能跟別的用途撞在一起。
- **`commit_version` 一定要進去**：`fairness.ts:277-283` 那段註解講得很清楚 ——
  「我用哪一套規則序列化」本身就是承諾的一部分，不能讓驗算端「試 v2 不行再試 v3」。
- **`client_seed_source` 一定要進去**：不然平台可以事後宣稱當初鎖的是別輪。
- `total_tickets` 是廉價的一致性檢查。

### 1.3 死線不是「開賣前」，是「drand 那一輪出現之前」

**這是這一輪最重要的判斷，也是最容易搞錯的一點。它決定了所有後面的選型。**

要擋的攻擊很具體：**平台看到 drand 亂數之後，回頭改資料庫裡的 `server_seed` 與 `commit_hash`**，
磨到一組讓自己人中 A 賞的種子，再宣稱本來就是那個。commit 存在我們的 DB，我們改得動。

```
T          commitPool()   種子產生、commit 寫進 DB、鎖定 drand 第 R 輪
T + 2 分   drand 第 R 輪的亂數公開                  ← 死線就在這裡
T + 2 分   openPool()     算完籤位、開始賣
```

**錨定晚於 drand 那一輪，就完全擋不到磨種子。**
它只證明「這串東西在某個晚一點的時刻存在」，而攻擊正好發生在那之前。

兩個推論：

- **預算是約兩分鐘，而且可調。** `pools-service.ts:79` 的 `FUTURE_ROUNDS` 從 4 改成 40 就變 20 分鐘，
  代價是賣家按下開池到真的開賣多等 18 分鐘。**這是產品決定，不是技術限制。**
- **現在的程式已經天然有這個空窗。** 池在 `commitPool()` 之後是 `committed`，
  `openPool()` 之前不賣任何一張票（`pools-service.ts:186`）。
  **錨定可以做成 `committed → open` 之間的一道硬閘門：錨沒上去就不開賣。**
  不用新增狀態、不用改流程形狀。

## 二、成本（2026-09-05 實測）

> 以下數字是 2026-09-05 從**台灣網路直連各鏈 public RPC** 量到的 gas，
> 配 CoinGecko 當日幣價算出來的。**是那一個時點的快照，不是報價。**
> 原型裡每一格都可以改，就是因為這個。
> 幣價：ETH $2,478.34｜SOL $103.82｜POL $0.095｜BTC $79,953

### 2.1 一筆錨定交易的 gas

**22,280 gas** ＝ 21,000 ＋ EIP-7623 的 calldata floor（32 bytes 全非零 → 128 tokens × 10）。
實測 `eth_estimateGas` 回 22,615，與計算一致。

**不需要智慧合約** —— 把 32 bytes 寫進一筆普通交易的 calldata 就夠了。
沒有合約就沒有合約風險、沒有升級、沒有 admin key。

### 2.2 各鏈

| 鏈 | 單筆 USD | 確認 | 一天 100 池／年 | 判定 |
|---|---|---|---|---|
| **Optimism** | 0.0000591 | ~2 秒 | **$2.16** | 實測最便宜。L1 資料費只佔 6% |
| **Base** | 0.000334 | ~2 秒 | **$12.19** | 貴 5.6 倍但一年只差 $10。**要上鏈的話選這個** —— basescan 的連結一般人看得懂 |
| Solana（memo） | 0.000519 | 次秒級 | $18.95 | 最快。memo 無狀態、不用付 rent。但**不繼承 Ethereum 的安全性** |
| Polygon PoS | 0.000544 | ~2 秒 | $19.85 | **不建議**：獨立 PoS 鏈 |
| Arbitrum One | 0.001096 | ~1 秒 | $40.01 | 同量級，選型上分不出高下 |
| Ethereum L1 @0.45 gwei | 0.0248 | ~12 秒 | $907 | **問題不是貴，是波動**（見下） |
| EIP-4844 blob | 0.0000015 | ~12 秒 | ~$0.05 | ❌ **陷阱**：blob 資料約 18 天就被剪除 |
| Bitcoin OP_RETURN @1 sat/vB | 0.140 | ~10 分〜1 時 | $5,107 | ❌ 想要的 Bitcoin 背書 OTS 免費就給 |

**兩個實測發現值得單獨拿出來講：**

- **blob 之後，L2 的 L1 資料費已經不是成本了。** Base 的 L1 data fee 是 $0.0000026，**佔總成本 0.8%**。
  「上 L2 很貴因為要寫回 L1」這個直覺在 2026 年已經過期。
- **Ethereum L1 的問題是波動不是價格。** 量測當下 `eth_gasPrice` 是 0.087 gwei，
  但同時點 Blockscout 的 fast 是 2.07 gwei ——**差 24 倍**。尖峰 10 gwei 時一年會變 $20,154。
  為了「錨在 L1」這個敘事買這個曝險不划算。

### 2.3 要不要批次：不要

原型裡有一棵真的 Merkle 樹（100 片葉子、真的 inclusion proof、瀏覽器裡重算回 root）。
**結論是不要用它來省錢**：

- 一天一包，錨定會晚於 drand 那一輪最多 24 小時 → **磨種子那條路完全沒被擋到**。
- 要讓批次還有意義，包的間隔必須小於死線（2 分鐘），也就是一天 720 包 —— 那時候已經沒在省錢。
- 而省下來的是 **$12/年**（Base）。**拿最強的主張去換 $12，是很糟的交易。**

**批次唯一真正的用途是另一個問題**：證明「那一天**所有**的池都被錨了、沒有偷偷跳過作弊的那幾個」。
一天一包、公開那一包涵蓋的池編號區間，正好是做那件事的形狀。
**那個問題這一輪沒有解**（列在 §5 第 5 條）。

## 三、替代方案，與最後的判斷

### 3.1 全表（成本欄是一天 100 筆的年成本）

| 做法 | 成本／年 | 時間戳來自 | 過得了 2 分鐘死線 | 要害 |
|---|---|---|---|---|
| **什麼都不做（現況）** | $0 | 我們自己的資料庫 | — | 爭議時沒有第三方可以判斷誰在說謊 |
| **寫進公開 GitHub repo** | $0 | GitHub 的 commit 時間 | ❌ **不成立** | **commit 時間來自本機時鐘，GitHub 不驗證也不標記** —— 改系統時間或 rebase 就能偽造任意時間。而且 repo 是我們控制的，可以 force push。**作為外部時間戳完全不成立** |
| **RFC 3161 公開 TSA** | **$0** | 一家 CA 的簽章時鐘 | ✅ **秒回** | 單家是單點信任 —— **但可以同時打三家互相獨立的**。見 3.2 |
| **OpenTimestamps → Bitcoin** | **$0** | Bitcoin 區塊 | ❌ **6〜12 小時** | 協定與伺服器都活著（實測 9 台 calendar 有 8 台通、全部同步在同一個區塊高度），**但原始碼寫死 `--btc-min-tx-interval` 21,600 秒 × random(1,2)**，加上 6 個確認與 conf-target 1008 的低費策略，完整背書要數小時到一兩天 |
| Sigstore Rekor | $0 | 公開 append-only 日誌 | ✅ 秒級 | 實例活著（tree size 416 萬），可用自產金鑰。**但官方明講每年換實例、舊實例會關掉、不要 hardcode URL** |
| 憑證透明度（CT log） | ~$0 | CT log 的 SCT | △ 分鐘〜24h | SHA-256 hex 是 64 字元，**DNS 單一 label 上限 63 —— 塞不進去**，要先 base32；還要 100 個 DNS-01 挑戰、受 LE 每 7 天 50 張憑證的限制。本質是把 CA 當資料儲存用。**不建議** |
| **自己上 L2（Base）** | **$12** | 公開鏈的區塊時間 | ✅ 1〜2 秒 | 錢完全不是問題。代價是持幣，見 3.3 |

**「寫進公開 GitHub repo」那一行要特別看。**
使用者的 memory 裡原本的規劃就是這個 ——
**而實測結論是它作為時間戳不成立**（commit 時間是本機時鐘寫的，任何人可以任意填）。
GitHub 提供的是「公開可見性」，不是「時間可信度」。
要讓它有意義，得把 commit hash 再餵給一個真的時間戳服務 —— 那就回到上面那幾行了。

### 3.2 為什麼是 RFC 3161

2026-09-05 從台灣用 `openssl ts` 發真實請求，**12 家全部回 `Status: Granted` 且時間正確**：
DigiCert、Sectigo、IdenTrust、SwissSign、DFN、FreeTSA、Apple、Certum、Entrust、ai.moda、SSL.com、Microsoft。
Token 大小 3.9〜6.9 KB。

- **秒回** → 過得了死線，這是它勝出的第一個理由。
- **$0**，免註冊、免 API key。
- **不用持有加密貨幣** → §3.3 那整包不確定性直接歸零。
- **單家是單點信任 —— 那就打三家。** 建議 `ts.ssl.com`（3.9 KB，最小）
  ＋ `freetsa.org`（簽章有效到 2040）＋ `timestamp.digicert.com`（Adobe AATL 信任鏈）。
  **三家互相獨立的 CA 要一起跟我們串供才假得了，而成本還是 $0。**
- **法律可讀性**：RFC 3161 token 是稽核員與法院看得懂的標準格式。`.ots` 不是。
- Token 是自帶簽章的結構，**那家 TSA 之後倒了，舊 token 照樣驗得動**
  （已知有 5 家歷史上的 TSA 死掉，但這不影響已簽出的 token）。

**OpenTimestamps 當第二層**：把當天的 Merkle root 丟給 calendar，幾小時後補上 Bitcoin 等級的背書。
它過不了死線，所以不能當主力；但當「十年後還驗得動」的底墊剛剛好，而且一樣 $0。

### 3.3 上鏈唯一真正輸掉的地方

**不是錢（一年 $12），是持幣。**

VaultDraw 現在的狀態（讀碼）：`web3`／`ethers`／`solana`／`nft`／`metamask`／`onchain`
在 `src/` 與 `server/src/` **零命中**。
[vinciworld-comparison.md](vinciworld-comparison.md) D-1 那句話是「**這個零不是巧合，要守住**」。

付 gas 跟「使用者能不能把點數換成現金」無關，所以它**不是紅線問題**。但它帶來四件實際的事：

1. **台灣《虛擬資產服務法》2026-06-30 三讀通過**，從《洗錢防制法》的登記制升級為**許可制**，
   八類 VASP 業務。「非金融公司只持幣付自己的 gas」**法條沒有明文豁免、子法未定、查不到官方函釋**。
   〔我的解讀，非法律意見：實質上不落在那八類裡；但不確定性存在，而金額只有一年 $12。〕
2. **私鑰保管**。
3. **餘額監控** —— 錢包空了池就開不了。
4. **會計處理**：gas fee 怎麼列、要不要揭露，**查不到明確規範**。

**為了一個 TSA 免費就能做到的東西去踩這四件事，不划算。**

### 3.4 建議的順序

**第 0 步（現在就能做，成本 0，不碰任何鏈）：把 leaf 規格定死並公開。**

在池的「驗證」分頁上，除了現在已經揭露的 `commit_hash` 與 client seed 來源，
再把 §1.2 那個 leaf 的**組成公式與原文**一起印出來。

- 這是任何時間戳方案的前提。**格式沒定，錨到哪裡都一樣沒用。**
- 它本身就已經產生一個外部見證：**第三方（記者、社群、對手）現在就可以自己收集並保存這些 leaf。**
  一個不受我們控制的人在他自己的機器上記下 leaf 與時間，就是我們管不到的證據。
- 沒有任何下不了台的地方：定了規格但最後決定不做時間戳，什麼都沒損失。

**第 1 步（成本 0）：每個池 commit 之後，把 leaf 同時送三家 RFC 3161 TSA，卡在 `committed → open` 之間。**
三份 token（~15 KB）存起來並公開。三家全掛才擋得住開池 —— 或者設計成「至少一家成功就放行」。

**第 2 步（成本 0）：每天把當日所有 leaf 打成一棵 Merkle 樹，root 丟 OpenTimestamps。**
順便解掉 §2.3 最後提的那個問題的一半（那一天涵蓋了哪些池是公開的）。

**第 3 步（只在一種情況下做）：產品敘事需要「使用者自己在 basescan 上點得到那一筆」。**
那就 Base、每池一筆、$12/年。**先把第 3.3 節那四件事處理完再說。**

**如果最後決定連第 1 步都不做**（完全合理），
那第 0 步照做，然後**在 `rules.md` 第八節誠實寫一句**：
「承諾雜湊目前只存在我們的資料庫，還沒有外部時間戳。」
—— 這正是 [vinciworld-comparison.md](vinciworld-comparison.md) A-2 的同一個原則：
**產品沒做的事，不要讓對外的文件寫得像做了。**

## 四、原型

### 4.1 怎麼開

```
open docs/proto/chain-anchor.html
```

單檔、自包含、**不連外**（不載字體、不打 API、不連任何鏈）。
「不連外」本身是論述的一部分：**它示範了驗算不需要任何伺服器。**

改了 `src/shared/fairness.ts` 之後重新產生內嵌的驗算程式碼：

```
node docs/proto/build-anchor-proto.mjs
```

### 4.2 它走的流程

1. **封存** —— 獎品清單 → manifest v4 序列化 → `manifest_hash` → `commit_hash`，鎖定 drand 未來輪次
2. **錨定** —— **死線分析**、leaf 規格、單筆錨定、Merkle 批次（可拉 1〜500 個池）
3. **開獎** —— drand 亂數到位、40 個籤位排完
4. **重算** —— **真的跑 `verifyReveal()`**，四條檢查 ＋ 第五條鏈上比對

## 五、它不能證明什麼

**這一節是這份文件最重要的一節。誇大這一點就是變成另一個 Renaiss。**

時間戳只證明一件事，而且只有一件：
**「這串 32 bytes 在那個時刻之前就已經存在了。」**

以下每一條**還是**要靠別的東西保證：

1. **不證明獎品清單誠實。** 賣家可以在開賣前就把爛卡標成 A 賞、把參考價灌水。
   它只讓他**改不了**，不讓他**一開始就誠實**。
2. **不證明實體卡真的存在。** 平台不代管實體卡，系統不知道賣家手上有沒有那張卡。
   一份不存在的卡的雜湊，鏈跟 TSA 都會照收不誤。
3. **不證明鑑定編號是真的。** `certNo` 只是賣家填的字串（PSA 查證已在 `migrations/029` 移除）。
   時間戳會把一個假的鑑定編號忠實地封存起來。
4. **不證明平台在別的地方沒作弊。** 出貨、市場撮合、點數帳、客服裁決、哪些池上首頁 —— 都不在這個雜湊裡。
5. **不證明「所有的池」都被錨了。** 有這一筆，只代表**這一個**池被錨了。
   平台大可以只錨乖乖的池、對作弊的池跳過不錨。（能堵的做法見 §2.3 最後一段，這一輪沒解。）
6. **不證明賣家會履行買回。** 買回價寫進承諾只讓它**改不了**；付得出來靠的是保留額與違約機制。
7. **對 99% 的使用者，它不會讓人更信任。** 會自己算雜湊的人本來就少。
   它真正的用途是：**吵起來的時候，第三方可以獨立判斷誰在說謊。**
   **它是給爭議準備的，不是給行銷用的。**

**還有一條要對自己誠實的：**
它**沒有讓 VaultDraw 的公平性變好** —— commit-reveal 與 drand 早就在跑了。
它只是把「開賣前就封存了」這句話的**見證人**，從我們自己的資料庫換成一群我們關不掉的第三方。
**提升的是可爭議性，不是隨機性。**
