# 台灣這一塊長什麼樣：抽選、市集、卡冊、鑑定

接續 `cardbase-comparison.md` 與 `vinciworld-comparison.md`。那兩份看的是香港的站，
這一份查的是**台灣本地**有哪些同類的東西。

查核日 2026-09-08，三條線平行查證：線上抽選平台、卡牌交易市集與卡冊工具、鑑定生態。
每一節末尾都有查不到的部分，不混進結論。

---

## 0. 先講結論

**「台灣主體 × 鑑定卡 × 線上抽選」目前是空的。** 但兩邊都在往中間靠。

台灣有成熟的線上抽選平台，也有成熟的卡牌交易市集，兩者都做得不錯 ——
但沒有人把它們合在一起，而且**沒有任何一家驗證鑑定卡殼的真偽**。

三個沒有人填的空白：

| 空白 | 現況 | 對 VaultDraw 的意義 |
|---|---|---|
| **公正性** | 讀過條款的六家台灣抽選平台，**零家**有雜湊承諾、事前 commit 或第三方隨機源 | 做 commit-reveal 在台灣是第一個 |
| **鑑定驗真** | 卡拍拍、iCard、Yahoo 都只把「PSA 10」當成一個字串標籤 | 假卡磚是真實痛點，這一格完全沒人做 |
| **台灣本地行情** | 皮卡屋、呼卡的資料全部來自 SNKRDUNK 與 eBay | 有市集就自然長出台灣成交資料，那是別人買不到的資產 |

而且時間不站在你這邊：
- **oneone 的商品分類裡已經有「鑑定卡」一格**（`/category/305`）
- **抽抽一番賞有獨立的「抽卡機」分頁**（`/cardDrawingMachine`）
- 日本的 Clove、DOPA、TCG JAPAN 正在台灣大量投放業配

### 1.1 兩件值得直接抄的條款寫法

**多巴胺是唯一把七日排除的法源寫明白的**：
> 依據《消費者保護法》及《通訊交易解除權合理例外情事適用準則》規定，
> 一番賞、盲盒屬於「機率性商品」，一經線上抽選或拆封後，其價值即受影響
> 且無法復原。

⚠️ **這是他們的主張，不是主管機關的認定。** 該準則第 2 條的例外事由是否真的
涵蓋「線上抽選」有解釋空間。而且 `payment-gateway.md` 五已經查到：消保處
109/6/19 的函釋要求告知必須寫在**個別商品旁的簡介頁面**、不能只埋在條款裡。
鑑定卡單價高、爭議金額也高，這一格不能含糊。

**多巴胺的點數二分法一定要有**：儲值進來的代幣，跟行銷送的紅利，
要在條款與帳本上分開。不分開的話，你送出去的每一點都是可退款的負債。

### 1.2 市場分歧最大的一點

**oneone 明文承認消保法 19 條，多巴胺明文排除。** 同一個市場、同一種商品，
兩家最大的平台寫了相反的條款。這代表這一格沒有安全的市場慣例可以躲，
你選哪一邊都要自己承擔理由。

### 1.3 你已經領先的兩件事

- **未成年門檻**：oneone 與賞翻天都還寫「未滿二十歲」，那是舊民法用語，
  現行成年年齡已是 18 歲。VaultDraw 的條款與首頁寫的都是 18 歲，是對的。
- **「不可提領現金」這句話，台灣平台上一次都沒讀到原文。** 大家用
  「不予折現」「不得接受退款」繞過去。VaultDraw 的首頁直接寫了
  「點數僅可用於站內抽選與兌換商品，不可提領現金或轉讓」——
  以刑法 266 的風險而言，這比市場慣例保守，是對的。

### 1.4 真正在做卡牌 oripa 的，全是日本主體

Clove（東京千代田區，號稱港台會員 110 萬）、日本卡牌中心 JTCC、DOPA、
TCG JAPAN、DawnTCG、Oripa.win。全部日本直送台灣，繁中介面。

其中兩個做了台灣沒有的事：
- **DOPA**：抽中可選擇「換回點數繼續抽」，正是回收機制。
- **DawnTCG**：每包在購買前公開機率並附 **SHA-256 封印**。
  （引自搜尋摘要，未逐字驗證官網原文。）

**卡拍拍是你最直接的對手** —— 市集、託管、卡冊、行情它全都有。
差異點只能打在鑑定驗真上，因為它只把鑑定當標籤。

**iCard 的託管寫法最務實**：「收到後 7 天自動放款」＋「上架前強制實名」。
這組合可以直接對照 VaultDraw 現有的鑑賞期設計。

**TCGSTORE 的分時間窗評分**（7/30/90/365 天）值得抄 —— 單一總分藏得住
「最近開始變差」，多時間窗藏不住。

### 2.1 但台灣主流成交其實不在這些站上

從代送鑑定到高價卡買賣，**大量成交發生在 LINE 群組與 Facebook 社團**，
靠信任與面交，沒有託管。888卡牌市集（FB 社團＋IG＋LINE OpenChat＋實體卡展攤位）、
各代送業者的 LINE 社團都是這樣運作的。

這是機會也是難題：**你要打的不是卡拍拍，是「大家習慣在群組裡喊價面交」這件事。**

## 3. 卡冊與行情工具（cardbase.io 的台灣對應）

- **皮卡屋 Pikawu** —— 最接近的一個，而且已經在收訂閱費。形態是 **LINE Bot**
  不是 App。功能：PSA 行情與走勢、照片辨識搜尋、**多本卡冊**、損益計算、
  鑑定預估（分析置中）。資料整合 SNKRDUNK 與 eBay。
  **它證明了台灣人願意為卡冊加行情付訂閱費。**
- **呼卡 Huca** —— PTCG 比價，中文搜日版與美版，支援 PSA 卡號搜尋，
  資料同樣來自 SNKRDUNK 與 eBay。
- **Cardex Go** —— 「K 線走勢分析、持倉管理」，措辭最金融化。
  營運方、是否台灣團隊、收費方案，站上都沒標。

**三家的資料全部來自日本與美國市場。** 皮卡屋自己在條款裡寫了免責：
數據未含台灣代購費、平台費、刷卡費與進口稅，實際交易建議依台灣行情。

**台灣本地成交行情是空的，而那是你有市集就會自然長出來的東西。**

## 4. 鑑定生態

### 4.1 編號驗證：只有 PSA 能用程式驗

| 機構 | 公開查詢 | 公開 API |
|---|---|---|
| **PSA** | psacard.com/cert/{號} | **有**，免費層約 100 次／日 |
| BGS | beckett.com 查詢頁，免登入 | 無 |
| CGC | cgccards.com/certlookup/ | 無，**且擋伺服器端抓取** |
| ARS | ars-grading.com/search，可依編號或卡名 | 無 |
| TAG | taggrading.com cert search（8 碼） | 無 |
| SGC | gosgc.com/cert-code-lookup | 無 |

**對程式的直接結論**：非 PSA 的卡實務上只能「導連結給人工核對」。
PSA 那條要快取結果，免費層一天 100 次撐不住流量。
另有 GemRate Partner API 宣稱可跨家用編號查詢，**該頁擋抓取，未證實，值得自己去問。**

### 4.2 你目前只認三家

`src/shared/domain.ts` 的 `Grader` 是 `'PSA' | 'BGS' | 'ARS' | 'RAW'`。

市場上實際在流通而你收不了的：**CGC、TAG**（卡拍拍支援）、
**SGC、BRG**（Yahoo 收藏卡專區的獨立分區）。
BRG 那一格影響的主要是**球員卡**，那一塊台灣的重心明顯在 Yahoo 拍賣。

### 4.3 假卡磚才是真正的痛點

台灣買家已經在自備紫光燈照 UV 水印、掃 QR 碼核對官方資料庫。
辨識手法分三種：假殼假卡、真殼假卡、真殼破解重封（低價卡塞進高分真殼）。

**光驗編號存在是不夠的** —— 真號碼可以被複製到假殼上。可行的層次：

1. PSA 走 API 驗號，並**存下官方回傳的分數、卡名與官方掃描圖網址**
2. 要求賣家上傳實物正反照，與官方掃描圖比對（真殼假卡只有這一關擋得住）
3. **同一 cert number 在站上重複出現要標記**（重封與盜圖都會撞號）
4. 非 PSA 的殼，商品頁強制附上該機構官方查詢連結與號碼
5. 高價品走託管＋開箱存證

第 3 點你已經有一半：`listings_cert_live` 擋的是「同一編號同時只能有一筆有效掛單」。

## 5. 小羊卡牌社：現成的市場論述

2026 年 8 月，台北萬華成都路的卡牌店無預警停業。鄭姓負責人失聯、疑已出境，
網傳金額逾 3 億元，自救會群組破 4,500 人，台北地檢署已分「他」字案交黑金組偵辦。

**那家店的業務型態正是「卡牌代購、預購、寄賣及代送國際鑑定服務」。**

受害結構是：**卡片與錢都交給第三方保管，沒有託管，沒有可稽核的持有證明。**

這對 VaultDraw 有兩個意義：

- **你的架構天生避開這個失敗模式。** 第 9 節的行紀模式（見 `payment-models.md`）
  更正過之後是**賣家直寄、平台不持有實體卡**。小羊那種倒法要成立，
  前提是東西在店家手上。
- **但你要能證明。** 「我們不持有」這句話本身沒有說服力，
  要靠可稽核的持有紀錄與出貨存證把它變成看得見的事實。

## 6. 沒解決的矛盾與查不到的

**一個矛盾要先標出來，不要當結論用：**

鑑定那條線的查證結論是「**台灣沒有本土鑑定公司**，只有代送」。
但市集那條線找到 **BRG**，並稱它是台灣本地鑑定商，Yahoo 收藏卡專區
給了它獨立分區。BRG 沒有獨立官網，只有臉書專頁。
**兩邊都沒查死，要自己確認一次。**

**查不到的：**

- **Dcard 兩篇線上一番賞平台比較文**（`/f/toy/p/261216739`、`/f/toy/p/258286751`）
  被 Cloudflare 擋，網頁與 API 都回 403。這兩篇是最有價值的第一手評比，
  **建議自己用瀏覽器開。**
- **oneone 的「鑑定卡」分類實際商品**（`/category/305`）—— JS 載入，抓不到。
  這是這輪最想看到而沒看到的一頁。
- **cc1kuji「抽卡機」的實際內容、機率揭露、付款與點數規則** —— 條款頁純前端渲染。
- **卡拍拍與 TCGSTORE 的實際抽成費率** —— 條款只寫「扣除手續費」，沒有數字。
- **蝦皮是否有卡牌一級分類**、露天的卡牌分類頁 —— 抓不到。
- **各 LINE 社團與 FB 社團的內部交易規則與成交量** —— 知道存在，讀不到內部。
- 樂翻 SLOT FUN、再來一抽 —— SPA 空殼，零內容。
- 玩得瘋的公司主體與統編 —— 站上沒有。
